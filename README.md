# cook_it_up

A new Flutter project.

## Getting Started

### Data Files
The following large data files are required for the backend (`recipe.py`) but are not included in this repository because they exceed GitHub's file size limits:
- `RAW_recipes.csv`
- `RAW_interactions.csv`

Please download these files (e.g., from the [Food.com Recipes and Interactions Kaggle dataset](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions)) and place them in the root directory of the project before running the server.
